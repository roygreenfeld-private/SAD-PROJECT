# SAD Project

Group project for the Information Systems Analysis & Design course at Ben-Gurion University. A full analysis and design of an information system for a real-world organization: business process modeling (BPMN), requirements analysis, and UML design (use case, class, and state diagrams).

## Repository structure

| Folder | Content |
|---|---|
| `part-a` | Part A |
| `part-b` | Part B |
| `part-c` | Part C |

Each part contains:

| Subfolder | Content |
|---|---|
| `documents` | Written documents |
| `mcps` | MCP files and configuration |
| `images` | Images and diagram exports |
| `work-process-docs` | Documentation of the work process |
